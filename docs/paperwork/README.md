# Submission paperwork (due 2026-11-24)

Three documents are due per course, submitted by the **team leader only** as one
package per course. These are fill-in templates — only identity fields and
team-specific choices need completing; the technical content is already written
from the real system in this repo.

## What to submit (per course: CNC 418, CNC 411, CNC 419)

| Step | File | What you fill in |
|---|---|---|
| **1 — Individual background** | [`Step1_Individual_Background_TEMPLATE.md`](Step1_Individual_Background_TEMPLATE.md) | One per member: name, ID, section, your own research background. |
| **2 — Team contract** | **[`Step2_Team_Contract_FILLABLE.pdf`](Step2_Team_Contract_FILLABLE.pdf)** (ready to submit) · source: [`Step2_Team_Contract_TEMPLATE.md`](Step2_Team_Contract_TEMPLATE.md) | Member names/IDs/sections + signatures (typed name + date is accepted). |
| **3 — Preliminary proposal** | [`Step3_Proposal.md`](Step3_Proposal.md) | Cover-page identity fields only — the rest describes the built system. |

## File naming (from the assignment)

```
TeamXX_Step1_<LastName>.pdf
TeamXX_Step2_Contract.pdf
TeamXX_Step3_Proposal.pdf      (e.g. Team03_CNC418_Proposal.pdf)
```

Export each Markdown file to PDF before submitting.

**Team contract is already a fillable PDF:** open
`Step2_Team_Contract_FILLABLE.pdf` in Edge or Acrobat, type into the boxes
(team, members, signatures; the team-agreement values are pre-filled and
editable), save, and submit it as `TeamXX_Step2_Contract.pdf`. Use
*Print → Save as PDF* if you want the typed values locked in.

## Rules to remember

- Team of **at most 5**, same team across all three courses.
- Every member must be able to **explain and defend any part** of the submission
  in the oral defence — not just their own module.
- The proposal must not contradict the capstone handout's scope/guardrails.
- **AI-use disclosure** is required: a short note is already included at the end
  of `Step3_Proposal.md` — keep it honest and edit to match what you did.
